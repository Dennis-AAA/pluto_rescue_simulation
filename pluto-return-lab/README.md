# 冥王星返航计划 · 引力实验室

交互式探索冥王星逃逸太阳、轨道救援、发动机预算、土星捕获与撞击代价。可调整初始速度、推进方向、行星引力、发动机比冲等参数，播放轨迹并导出数据。

本项目是二维、理想化教学模型，土星捕获采用独立的局部二体场景，不构成真实航天任务规划。模型假设、计算推导和参考资料见网页下方的“计算手记”。

打开 `index.html` 即可使用；`offline.html` 为可单独运行的单文件版本。不需要安装依赖或运行构建工具。

可将仓库的默认分支根目录用于 GitHub Pages 静态网站发布。`index.html`、`style.css`、`physics.js` 和 `app.js` 分别包含页面、样式、物理模型和交互代码。
